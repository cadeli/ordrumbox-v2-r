Making beats with an AI assistant

A beginner's guide to the orDrumbox MCP link — see also the user manual, section 19

In one sentence: you connect an AI assistant (such as Claude) to orDrumbox, then you ask it in plain words — "make me a hip-hop beat at 90 BPM" — and it edits the patterns in the orDrumbox window while you watch and listen. You do not need to know any programming.

1. What is MCP?

MCP (Model Context Protocol) is a standard way for an AI assistant to use a program on your computer. orDrumbox offers a set of tools — "list the patterns", "add notes", "change the tempo", "play"… — and the assistant chooses which ones to call to do what you asked.

  • Every change appears at once in the orDrumbox window.
  • Every change is one step of Edit › Undo (Ctrl+Z): nothing the assistant does is final.
  • Every change is saved with your library, like your own edits.
  • The link stays on your computer: orDrumbox only accepts connections from the same machine (127.0.0.1), with a secret token.

2. Setting it up (once)

Step 1 — Find the path of the orDrumbox program

The assistant needs to know where the program is. It is the full path of the file you start:

SystemExample of path
WindowsC:\Programs\ordrumbox\ordrumbox.exe (where you unpacked the zip)
macOS/Users/you/ordrumbox/ordrumbox

Tip: on Windows, hold Shift, right-click ordrumbox.exe and choose Copy as path. On macOS, select the file in the Finder and press ⌥ Option+⌘ Cmd+C.

Step 2a — With Claude Desktop

  1. Open Claude Desktop, then Settings › Developer › Edit Config. This opens the file claude_desktop_config.json.
  2. Put this in it (replace the path with yours). If the file already has an "mcpServers" section, add only the "ordrumbox" entry inside it. 
    {
  "mcpServers": {
    "ordrumbox": {
      "command": "C:\\Programs\\ordrumbox\\ordrumbox.exe",
      "args": ["--mcp"]
    }
  }
}
  3. Save the file, then quit Claude Desktop completely and start it again.
Windows: in this file every backslash is written twice: C:\\Programs\\ordrumbox\\ordrumbox.exe, not C:\Programs\ordrumbox\ordrumbox.exe. Forward slashes also work: C:/Programs/ordrumbox/ordrumbox.exe.

Step 2b — Or with Claude Code (in a terminal)

claude mcp add ordrumbox -- /path/to/ordrumbox --mcp

Other MCP clients (Cursor, …) take the same two things: the command (the program's path) and the argument --mcp.

Step 3 — Start orDrumbox

The assistant drives the open window. Start orDrumbox as usual, before you ask anything, and keep it open.

3. Checking that it works

With orDrumbox open, ask the assistant:

What patterns do I have in orDrumbox?

The assistant calls the tool listPatterns (the client may ask you to allow it the first time: accept) and answers with the names of your patterns, for example those of the demo library. If it says that orDrumbox is not running, start the program and ask again.

4. Five ideas to know

You can talk naturally, but knowing these words helps you ask precisely and understand the answers.

A pattern

A short loop, usually one measure of 4 beats, played at the session's tempo (BPM; a song has its own). Patterns have a name; you refer to them by it ("the pattern Funky"), in any case.

A track

One line of the pattern, one sound. A track is named after its instrument: KICK, SNARE, CLAP, CHH (closed hi-hat), OHH (open hi-hat), TOM, COWBELL, CRASH, BASS… Ask "which instrument names can I use?" for the full list.

A step

Each beat is cut into steps, 4 by default (sixteenth notes). Steps are counted from 0, across the whole pattern: a 4-beat pattern has steps 0 to 15. You rarely need the numbers — "on every beat" is enough — but they are what the assistant sends, and what it may tell you back.

Beat1234
Step0123456789101112131415
Kick on every beat●●●●
Snare on 2 and 4●●
Hi-hat on eighths●●●●●●●●

The formula, if you like it: step = (beat − 1) × 4 + position in the beat.

A kit and a synth

A kit is a set of samples (electro, real, 8bits…): changing the kit changes the sound of every drum track. A synth preset (BASS_ACID, SYNTHLEAD_SAW, PIANO_EPIANO…) is a sound made by the built-in synthesizer, handy for bass lines and chords.

An arrangement (song)

Patterns placed one after the other on a timeline, measure by measure. Measures are also counted from 0: the first measure is measure 0.

5. Examples, step by step

Each example shows what you can say, what the assistant does behind the scenes (the tool it calls, with its settings, so you can follow along), and what you will see in the window. You never have to type the tool calls yourself.

Example 1 — Your first beat from scratch

Create a pattern called "First Beat" at 95 BPM: kick on every beat, snare on beats 2 and 4, closed hi-hat on every eighth note. Then show it and play it.

The assistant calls, in order:

createNewPattern   { "patternName": "First Beat" }
setBpm             { "bpm": 95 }
addNotesToPattern  { "patternName": "First Beat", "notes": [
  { "trackName": "KICK",  "step": 0 }, { "trackName": "KICK",  "step": 4 },
  { "trackName": "KICK",  "step": 8 }, { "trackName": "KICK",  "step": 12 },
  { "trackName": "SNARE", "step": 4 }, { "trackName": "SNARE", "step": 12 },
  { "trackName": "CHH", "step": 0 },  { "trackName": "CHH", "step": 2 },
  { "trackName": "CHH", "step": 4 },  { "trackName": "CHH", "step": 6 },
  { "trackName": "CHH", "step": 8 },  { "trackName": "CHH", "step": 10 },
  { "trackName": "CHH", "step": 12 }, { "trackName": "CHH", "step": 14 } ] }
selectPattern      { "patternName": "First Beat" }
play               { }

You see a new pattern at the end of the list, with three tracks filled exactly like the grid of section 4, and you hear it loop. The tracks did not have to exist: adding notes to KICK creates the KICK track.

Example 2 — Let orDrumbox generate a pattern in a style

Which styles do you know? … OK, make me a new house pattern.

listStyles       { }
generatePattern  { "style": "house" }

orDrumbox writes a whole pattern itself — tracks, swing, lines, and the session's tempo — as Pattern › New pattern in the style does. Not happy with it?

Make it again, with more energy.

regeneratePattern { "patternName": "…", "style": "house" }
setPatternMacro   { "patternName": "…", "macro": "energy", "value": 80 }

The three macros, energy, complexity and variation, go from 0 to 100; 50 changes nothing.

Example 3 — Mixing: volume and stereo position

In "First Beat", make the hi-hat quieter and put it a bit to the left.

updateTrack { "patternName": "First Beat", "trackName": "CHH",
              "updates": { "volume": 0.6, "pan": -0.4 } }

volume 1 is the normal level; pan goes from −1 (left) to 1 (right). If a value is out of range, orDrumbox brings it inside and the assistant tells you the value used.

Example 4 — Groove: accents, ghost notes and chance

Add soft snare ghost notes just before beats 2 and 4, and make every hi-hat play only 80 % of the time.

addNotesToPattern { "patternName": "First Beat", "notes": [
  { "trackName": "SNARE", "step": 3,  "velocity": 0.3 },
  { "trackName": "SNARE", "step": 11, "velocity": 0.3 } ] }
updateTrack { "patternName": "First Beat", "trackName": "CHH",
              "updates": {}, "noteUpdates": { "probability": 0.8 } }

A note's velocity (how hard it is hit) and probability (its chance to play) go from 0 to 1. With a probability below 1, the hi-hat changes a little at every loop: the beat feels more alive.

Example 5 — A synth bass line

Add a bass playing on the synth preset BASS_ACID: a note on step 0, then a fifth higher on step 6, then back on step 10.

updateTrack       { "patternName": "First Beat", "trackName": "BASS",
                    "updates": { "useSynth": true, "synthPreset": "BASS_ACID" } }
addNotesToPattern { "patternName": "First Beat", "notes": [
  { "trackName": "BASS", "step": 0 },
  { "trackName": "BASS", "step": 6, "pitch": 7 },
  { "trackName": "BASS", "step": 10 } ] }

A note's pitch is in semitones from the track's note (7 = a fifth, 12 = an octave). Ask "which synth presets are there?" to hear other sounds.

Example 6 — Change the whole drum sound

Which kits do I have? Switch to the electro kit.

listKitSamples { }
selectKit      { "kit": "electro" }

Every track whose sound follows its name takes the sample of the new kit. Changing back is as easy: "switch to the real kit".

Example 7 — Build a short song

Make a song called "Demo song": 4 measures of "Intro", then 8 measures of "First Beat", then 4 measures of "Intro" again. Play it.

createArrangement { "name": "Demo song", "clips": [
  { "patternName": "Intro",      "startMeasure": 0,  "measureCount": 4 },
  { "patternName": "First Beat", "startMeasure": 4,  "measureCount": 8 },
  { "patternName": "Intro",      "startMeasure": 12, "measureCount": 4 } ] }
play { "song": true }

The song panel shows the three clips. Without measureCount, a clip lasts as long as its pattern; "repeat the clip at measure 4" doubles it (repeatClip).

Example 8 — Export to share

Export "First Beat" as a WAV file and as MIDI, and the song "Demo song" as WAV.

exportPatternWav     { "patternName": "First Beat" }
exportPatternMidi    { "patternName": "First Beat" }
exportArrangementWav { "arrangement": "Demo song" }

The files go to the exports folder of your user data folder (see the user manual, section 1); the assistant tells you their full path.

Example 9 — Oops: undo

No, I preferred it before. Undo the last two changes.

undo { }
undo { }

You can also simply press Ctrl+Z in the window: the assistant's edits and yours share the same undo history. redo brings a change back.

6. Writing good requests

  • Name the pattern you mean: "in First Beat, …". Otherwise the assistant has to guess or ask.
  • Use musical words: "on every beat", "on the off-beats", "on beats 2 and 4", "every sixteenth note", "a fifth higher". The assistant turns them into step numbers.
  • One idea at a time when you start: you hear each change and can undo just that one.
  • Ask it to look first: "describe the pattern Funky" (it calls loadPattern) before "make it groovier". It then knows what is there.
  • Ask for explanations: "why does the hi-hat sometimes skip?" — it can read the settings and tell you.
  • Be bold: everything is undoable, and you can always ask for a copy first ("duplicate Funky as Funky 2, then work on the copy").

7. When something goes wrong

What you seeWhat to do
"orDrumbox is not running"Start orDrumbox, keep its window open, and ask again.
The assistant does not know about orDrumbox, or has no orDrumbox tools Check the path in the client's settings (on Windows, double backslashes), then quit and restart the client completely.
A tool is refused while a question is open in the window orDrumbox is waiting for you to answer a confirmation (for example "Factory reset?"). Answer it in the window, then ask again.
"No pattern named …"Ask "what patterns do I have?" and use one of the names it gives.
A value is not the one you asked for It was out of range (tempo 20 to 300, at most 16 beats…): orDrumbox used the nearest allowed value and the answer says which.
Undo does not bring back a synth preset, the master or a kit Changes to synth presets, the master bus and kits are saved with the settings, not in the undo history. Ask the assistant to set the old values back.
